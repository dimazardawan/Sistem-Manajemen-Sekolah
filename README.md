# Sistem Manajemen Sekolah (School Management System)

Aplikasi desktop berbasis **Java** yang dirancang untuk mengotomatisasi dan mempermudah proses manajemen administrasi di lingkungan sekolah. Proyek ini dibangun menggunakan NetBeans IDE dengan antarmuka berbasis GUI (Graphical User Interface).

## ✨ Fitur Utama (Perkiraan)
- Manajemen Data Siswa: Input, edit, dan hapus data murid.
- Manajemen Data Guru: Pengelolaan informasi tenaga pendidik.
- Administrasi Kelas: Pengaturan kelas dan mata pelajaran.

## 🛠️ Teknologi yang Digunakan
- Bahasa Pemrograman: Java
- IDE: NetBeans IDE
- Build Tool: Apache Ant
- Framework GUI: Java Swing / AWT
